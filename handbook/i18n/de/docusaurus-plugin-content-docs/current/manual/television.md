# Der Fernseher

Öffnest du die Adresse der Box im Browser eines Fernsehers, ist die
Seite die TV-Ansicht: der ganze Bildschirm, große Schrift und ein Ring
um das, worauf die Fernbedienung steht. Ein Computer bekommt weiter den
Schreibtisch, die Admin-Seiten mit der Seitenleiste. Der eigene
Bildschirm der Box, wenn sie einen hat, zeigt weiter das Adressbanner
auf tty1. Der Fernseher ist ein Browser, der auf die Box zeigt, nicht
dieses Banner.

![Die TV-Ansicht auf einem 1080p-Gerät: der Name der Box, die Uhrzeit, ob sie antwortet, wie voll die Platte ist, und die Apps, mit dem Fokusring auf der ersten Kachel.](@site/docs/img/tv/tv-home-de.png)

## Was du siehst

Der Startbildschirm nennt die Box und zeigt die Uhrzeit. Darunter liegen
zwei Kacheln. **Die Box** sagt, ob sie antwortet. **Platte** sagt, wie
voll sie ist, sobald du angemeldet bist. Darunter stehen die Apps, die
wirklich da sind: Dateien, Fotos, Code, Issues. Einstellungen ist auch
da. Sie öffnet nicht die Formulare. Sie öffnet **Schreibtisch**, und
der sagt, dass diese Formulare für einen Computer aus der Nähe sind.

Dateien, Fotos, Code und Issues öffnen ihre eigenen Seiten. Zurück auf
dem Gerät bringt dich zur TV-Ansicht.

Die Ränder bleiben in dem Streifen, den ein Fernseher abschneiden kann,
bei 1080p und bei 4K. Die Schrift wächst mit dem Bildschirm, damit ein
4K-Gerät vom Sofa aus genauso lesbar ist.

## Die Fernbedienung

Eine Maus brauchst du nicht.

- **Pfeile** setzen den Ring auf die nächste Kachel. Am Rand des
  Bildschirms springt er nicht auf die andere Seite.
- **OK** oder Enter öffnet, worauf der Ring steht.
- **Zurück** (Escape auf einer Tastatur) geht zum vorherigen Bildschirm.
  Auf dem Startbildschirm bleibt er. Während du tippst, löscht
  Rücktaste zuerst ein Zeichen.
- **Home** kehrt von überall in der TV-Ansicht zum Startbildschirm
  zurück.
- **Schreibtisch** verlässt die TV-Ansicht und öffnet die Admin-Seiten
  wie an einem Computer.

Der Ring wird gezeichnet, sobald etwas den Fokus hat, auch von einer
Fernbedienung, die nie einen Zeiger bewegt.

## Wann sie sich öffnet

Sie öffnet sich von selbst, wenn der Browser wie ein Fernseher aussieht:
Android TV, Apple TV, Fire TV, Chromecast, webOS, Tizen und die anderen
Geräte, die die Box erkennt. An einem Computer öffnest du das Menü der
Person, dann **TV-Layout**, dann **Ein**, und du siehst dieselbe
Ansicht. **Wenn der Browser wie ein TV wirkt** ist die übliche Wahl:
ein Fernseher bekommt die Ansicht, ein Computer nicht. **Aus** behält
den Schreibtisch auch auf einem Fernseher. Die Wahl bleibt in diesem
Browser gespeichert.

Eine Box, die noch niemand eingerichtet hat, zeigt weiter den
Einrichtungsassistenten. Die TV-Ansicht beginnt, wenn der Assistent
fertig ist.

Der Startbildschirm funktioniert, bevor sich jemand anmeldet. Der
Plattenwert und der Schreibtisch brauchen eine Anmeldung. **Anmelden**
ist ein großes Formular auf demselben Bildschirm. Zurück verlässt es.
