Sharing

Applying…

When on, the appliance contributes storage to the shared Longhorn pool (mesh mode). The shared data directory is unlocked from its own fscrypt key, so a pooled volume can be traced back to this box. When off, the box stays a private local appliance and that directory stays locked. Changing this triggers a full system rebuild.

Joining registers this box as a node of the shared cluster at the edge, so pooled storage can be replicated here. Sharing compute also lets the edge schedule mesh workloads on it, but only inside the window above. Outside it the edge marks the box unschedulable and the CPU is yours. An end time earlier than the start wraps midnight, which is the usual shape (23:00 to 07:00). Times are in this appliance’s own timezone — the edge is told which one, so a window means the same hours to you wherever the edge is. Changing any of this triggers a full system rebuild.

Container mode runs each service in an isolated system container; native mode runs it directly on the host. Switching modes triggers a full system rebuild.

The appliance is reachable as <hostname>.local on the LAN. The hostname is also used in the URLs handed to Nextcloud and Forgejo. The master proxy publishes the dashboard on a public hostname through a Traefik/rathole relay — leave it off for LAN-only access.

The Apache port is the host loopback port Nginx proxies to the Nextcloud container (valid range 1024–65535).

Factory reset Restore all appliance settings to factory defaults and rebuild.

Only losos.* settings are reset; your data on /persist is not touched. The rebuild starts immediately after confirmation.
